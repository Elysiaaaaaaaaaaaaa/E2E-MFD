## E2E-MFD 部署可行性分析（venv + Python 3.12 调研）
- 项目依赖：mmdet 2.26.0 + mmrotate 0.3.4 + mmcv-full 1.7.2 + e2cnn（git 安装），官方推荐 Python 3.9.17。
- 结论：**Python 3.12 部署不可行**。原因：① mmcv-full 1.7.2 官方预编译 wheel（download.openmmlab.com）最高只到 cp311，PyPI 仅有 sdist；② py3.12 源码编译 mmcv 1.7.x 会因 pkgutil.ImpImporter 移除等失败；③ mmcv-full 1.7.2 wheel 基于 torch 1.13/2.0，而 torch 2.0 不支持 py3.12（首个支持 py3.12 的是 torch 2.2），版本链死锁；④ mmrotate 0.3.4 官方仅声明 py3.6-3.9。
- 本机环境：无 NVIDIA GPU（nvidia-smi 不存在，只能用 CPU 版 torch）；可用 Python：3.9.13（C:\Users\86189\AppData\Local\Programs\Python\Python39，推荐）、3.13.14（默认，太新）、Astral CPython 3.12.11/3.11.13（uv 管理）。
- 项目目录中 mmcv/ 与 mmdet/ 是 **Linux + py3.9 安装后的拷贝**（mmcv 下有 `_ext.cpython-39-x86_64-linux-gnu.so`），Windows 上不可用，必须重装；dist/ 有 mmrotate-0.3.4-py3.9.egg，证明此前部署环境就是 py3.9。
- 推荐部署路径（待用户确认后执行）：Python 3.9 + venv + CPU 版 torch 1.13.1+cpu + mmcv-full 1.7.2（openmmlab cpu/torch1.13.0 目录的 win_amd64 cp39 wheel）。
- 坑点：不能直接 `pip install -r requirements.txt`（mmcv-full 会从 PyPI 装 sdist 触发源码编译失败），须先装 torch + mmcv-full wheel，再装其余依赖；e2cnn 从 git 装，Windows 上可能需 VS Build Tools 编译 cpp 扩展。

## RGB+IR 融合算法解读（用户询问，已完成）
- 结论：融合 = 可学习的"逐像素注意力加权融合"，在 HSV 亮度域完成，与检测器端到端联合训练。**不是传统算法**（小波/金字塔/固定加权）。
- 核心代码：mmrotate/models/detectors/fusion.py（FusionNet/Encoder/SKConv/Attentionregion/FusionBlock）+ oriented_rcnn_m.py（forward_fusion 融合公式）+ loss.py（DetcropPixelLoss）+ datasets/pipelines/loading.py（bri_clr_loader1 的 HSV 分解）。
- 融合公式（forward_fusion 第 684 行）：`fus_img = w_ir·IR + w_rgb·RGB_V`（res_weight 为 FusionNet 输出的 2 通道逐像素权重图，Sigmoid 归一化）。
- 流程：配准 RGB/IR → RGB 转 HSV 拆 V 亮度 + HS 颜色（IR 取单通道）→ 共享 backbone 双流提特征、4 层特征逐层相加 → FusionNet（Encoder：FusionBlock+SKConv 注意力+门控残差；block2 卷积→Sigmoid 输出 2 通道权重图）→ 加权融合 → 融合亮度 V + RGB 的 H/S 拼回 HSV→RGB 得彩色融合图。
- 训练损失（DetcropPixelLoss）：SSIM（融合图分别对齐 IR 与 RGB 亮度）+ 梯度损失（拉普拉斯金字塔 3 级，向 max(IR,RGB) 靠拢）+ 像素损失（gt 旋转框 mask 内对齐 max+(IR+RGB)/2，背景对齐 IR），融合损失×10 与检测损失联合。
- 生成融合图脚本：tools/generate_fusion_image.py（调用 model.forward_fusion，注意第 21 行硬编码 CUDA_VISIBLE_DEVICES='5' 需改）。
- **训练入口确认（用户追问）**：融合网络与检测器是**同一个入口端到端训练**——tools/train.py → mmrotate train_detector → 单个 Oriented_rcnn_m.forward_train 一次前向同时算 fusion_loss 与 detection_loss，返回 dict {fusion_loss, detection_loss, acc}（acc 只记录不计入 loss，mmdet 2.x _parse_losses 只对 key 含 'loss' 求和）；单个 AdamW（lr=1e-4, wd=0.05）一次 backward 更新 FusionNet/backbone/neck/RPN/RoI 全部参数。无两阶段、无融合预训练入口。
- 融合无真值图，是"无参考损失"：pixel 目标区域向 max(IR,V)+(IR+V)/2、背景向 IR 对齐（GT 旋转框外接矩形生成 mask，712×840 后 pad）；grad 用 3 级拉普拉斯金字塔向 max(IR,V) 靠拢；SSIM 分别对齐 V 与 IR；三部分各 ×10 求和。config: tools/cfg/lsk_s_fpn_1x_dota_le90.py（AdamW、samples_per_gpu=4、img 712×840）。
- 比赛数据：训练集 2000 张 + 测试集 1000 张，三模态 visible/infrared/depth（均为 RGB 编码），jpg/png 混合（训练 1851 png / 149 jpg；测试 845 png / 155 jpg），训练集 640×360 为主，测试集有 1 张 1920×1080。训练/测试 ID 无重叠，data 下无类别说明文件。
- 标签为 **YOLO 格式**（class cx cy w h 归一化水平框），12 类（用户提供映射）：0 person / 1 boat / 2 animal / 3 seat / 4 sign / 5 bicycle / 6 car / 7 ball / 8 light / 9 garbage_can（原含空格，DOTA 按空白分列必须去空格）/ 10 uav / 11 tricycle。总框数 14417，无空文件。
