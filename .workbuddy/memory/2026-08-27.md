## Kaggle 部署排障：numpy 2 不兼容
- 现象：Kaggle 上运行 tools/train.py，报 `_ARRAY_API not found`（torchvision 导入崩）+ matplotlib backend `module://matplotlib_inline.backend_inline` 无效。
- 根因：py39 环境里 numpy 被升到 2.0.2，而 torch 1.13.1 / torchvision 0.14.1 / mmcv-full 1.7.2 均基于 numpy 1.x 编译；matplotlib-inline 包缺失导致连锁报错。
- 修复：`pip install "numpy<2" matplotlib-inline`（py3.9 上最后 1.x 为 numpy 1.26.4）+ 重启 session；train.py 顶部加 `os.environ["MPLBACKEND"]="agg"`。
- 项目约束：README 明确要求 python 3.9.17（mmrotate 0.3.4 官方仅支持 py≤3.9），Kaggle 部署应保持 py3.9，勿用官方镜像默认 py3.10+；勿升级 torch（mmcv 1.7.2 只支持到 torch 1.13）。
